# TallerCorreccion

Proyecto en Java para el manejo de figuras geometricas.

## Figuras

- Circulo
- Triangulo
- Cuadrilatero
- Pentagono regular

## Funciones

- Calcular area
- Calcular perimetro
- Dimensionar
- Desplazar
- Escalar
- Comparar figuras

## GitFlow

- main: version estable
- develop: desarrollo
- feature: nuevas funcionalidades
- release: preparacion de entrega
- hotfix: correcciones criticas
